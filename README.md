# 🔀 Control Structures in C

A collection of basic C programs demonstrating **decision-making, conditional statements, and control structures**.

## 📋 Program List

* **`MultipleOrNot.c`**: Checks whether a number is a multiple of another number.
* **`NoOfDays.c`**: Determines the number of days in a given month.
* **`areaofatriangel.c`**: Calculates the area of a triangle.
* **`grades.c`**: Determines a student's grade based on their marks.
* **`leapyear.c`**: Checks whether a given year is a leap year.
* **`oddoreven.c`**: Determines whether a number is odd or even.
* **`roots.c`**: Calculates the roots of a quadratic equation.

## ✨ Highlights

* 🧠 **Decision Making:** Practice with `if`, `else`, and `else-if` statements.
* 🔢 **Number Logic:** Programs for odd/even numbers, multiples, and leap years.
* 📅 **Conditional Logic:** Determines the number of days in a month.
* 📊 **Grading System:** Uses conditions to assign grades based on marks.
* 📐 **Mathematical Problems:** Includes triangle area and quadratic equation roots.
* 💻 **C Fundamentals:** Strengthens logical thinking and programming fundamentals.

## 🧠 Concepts Covered

* `if` statements
* `if-else` statements
* `else-if` ladder
* Relational operators
* Logical operators
* Conditional logic
* Mathematical calculations
* Decision-making in C

## 🚀 How to Run

Compile and execute any program using GCC:

```bash
gcc filename.c -o output
./output
```

For example:

```bash
gcc oddoreven.c -o oddoreven
./oddoreven
```

## 📌 Purpose

This repository contains practice programs created while learning **control structures in C** and building a strong foundation in programming logic.
